# Regina Loves Pink

Regina Loves Pink is a web-based obstacle course game built using the Godot engine. 

How to Play
Navigate through the obstacle course using the following controls:
Move / Navigate: Arrow keys or `WASD` keys
Action / Jump: Spacebar

Project Details
Developer: asbah-html
Genre: Action / Platformer
Engine: Godot
Platform: HTML5 (Playable directly in the browser)
